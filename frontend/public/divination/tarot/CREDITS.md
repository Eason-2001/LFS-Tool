# 塔罗牌面素材说明

本目录 `0.jpg` ~ `77.jpg` 为 Rider-Waite（莱德·韦特）全套 78 张牌面插画：
`0–21` 大阿卡纳 22 张，`22–77` 小阿卡纳（权杖 / 圣杯 / 宝剑 / 星币各 14 张），
编号与 `apps/divination/tarot_data.py`、`tarot_minor.py` 中的牌 `id` 一一对应。
